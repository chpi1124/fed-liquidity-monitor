# 门禁登记表（自动生成）

本文件由 `node tools/publish.mjs` 从 `tools/gates.mjs` 派生，请勿手改：改了会被 G9 判成漂移。
每条门禁都必须可证红（负向对照见 `tools/selftest.mjs`），BLOCKED 状态一律按红处理。

| 编号 | 判据 | 失败含义 |
| --- | --- | --- |
| G0 | 静态：可解析·零依赖·无残件 | 源码不可解析 / 引入了依赖 / 仓库留下实验残件 |
| G1 | 校验覆盖：19/19 指标有校验腿 | 指标缺校验腿或缺 checkKind，或汇总行既无校验也无单源声明 |
| G2 | 阈值溯源：每个阈值带 source 且可复算 | 阈值没有可复算的来源声明，或实测已越带、带太松/太紧 |
| G3 | 数据红线：不造数·改值留痕·不绕 WAF | 出现造数字段、无痕改值、绕 WAF 逻辑或未登记的降级源 |
| G4 | 纠错有效性负向对照（需出网，--net 开启） | 注入错误值却没被纠错层抓到（需 --net 出网实跑） |
| G5 | 前端结构唯一性 | 取数/图表出口越界，或 tokens.css 之外出现字面色值 |
| G6 | 美学与可达（WCAG 2.2 AA） | 对比度不达 WCAG AA、动效超长或存在发光令牌 |
